# AllSurvey — опрос счётчиков через модемы

Программа для Windows. Обзванивает электросчётчики Энергомера СЕ30x через GSM-модемы и собирает показания в отчёт Excel.

- Звонит сразу через все подключённые модемы: номера делятся между ними.
- Неудачные номера (нет связи, занято, счётчик не ответил) перезванивает автоматически, каждый раз с другого модема.
- Сохраняет отчёт Excel: показания по тарифам, напряжение батареи, дату и время счётчика, а в конце — номера, которые опросить не удалось, с причиной.
- Обновляется сама.

Здесь лежат только готовые версии программы. Исходный код не публикуется.

## Установка

1. Откройте последний выпуск: **[Releases → Latest](https://github.com/Lonzo12/opros-updates/releases/latest)**.
2. Скачайте `Opros-<версия>.zip`. Остальные файлы (`latest.json`, `latest.sig`) нужны самой программе для обновлений.
3. Распакуйте архив в папку, куда у вас есть право записи, например `C:\Opros`.
   **Не распаковывайте в `C:\Program Files`**: туда программа не сможет записать обновление.
4. Запустите `C:\Opros\Opros\Opros.exe` и создайте ярлык на рабочем столе.

Python и другие программы устанавливать не нужно.

При первом запуске Windows может показать «Windows защитила ваш компьютер». Нажмите **«Подробнее» → «Выполнить в любом случае»**.

**Требования:** Windows 10 или 11 (64-бит), GSM-модемы с поддержкой CSD-вызовов, подключённые к COM-портам.

## Обновление

Ничего делать не нужно. При запуске программа проверяет, есть ли новая версия, и скачивает её в фоне, а затем спрашивает: «Установить сейчас?». После согласия она закроется и через несколько секунд откроется уже новой.

Каждое обновление подписано цифровой подписью разработчика. Программа проверяет подпись и не установит файл, если его подменили или повредили.

## Где хранятся данные

| Что | Где |
|---|---|
| Настройки (порты, пути, число повторов) | `%APPDATA%\Опрос счётчиков\settings.json` |
| Отчёты и журналы обмена (по умолчанию) | `Документы\Опрос счётчиков\` |
| Записи о непредвиденных ошибках | `%APPDATA%\Опрос счётчиков\ошибки.txt` |

При обновлении настройки и отчёты сохраняются.

## Удаление

Удалите папку с программой (например, `C:\Opros`). Если настройки тоже не нужны, удалите `%APPDATA%\Опрос счётчиков`.

## Если что-то не работает

Пришлите разработчику файл `%APPDATA%\Опрос счётчиков\ошибки.txt`. Если проблема с конкретным счётчиком, добавьте журнал обмена из папки `logs`.
